# refinery-handoff

特定の作業の引き継ぎを保存・再開・整理する、明示呼び出し専用のSkillです。
`$refinery-handoff`を指定し、操作と対象を依頼します。

本体は小さなルーターとして、作成時だけ`references/create.md`、再開時だけ`references/resume.md`、
整理時だけ`references/cleanup.md`を読みます。削除専用Skillは設けません。
現在のrepoと目的、または引き継ぎIDを入力とし、保存済みの資料と再開用依頼文、
現在の成果物に基づく再開結果、指定した資料の整理結果をそれぞれ返します。

通常の開発開始・完了、experience／memory検索、`--agents`自動運用では起動しません。
引き継ぎ本文の指示や過去の承認を、今回の依頼より優先しません。読み取りだけでは状態を変えません。
保存、置き換え、アーカイブは読み戻し、削除は結果と一覧からの不在を確認します。
同じ対象の終了時整理が依頼済みなら、もう一度Skillを呼ばせず同じ手順内で進めます。

利用例とライフタイムは[引き継ぎガイド](../handoffs.md)にあります。
配布する指示の正は`skills/refinery-handoff/SKILL.md`とその参照ファイルです。
